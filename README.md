The funniest error message a kitchen toaster would show its owner (76 characters):

> ERROR E07: Your toast has passed away. A small funeral will be held at noon.

The joke is deadpan escalation: the toaster reports the toast's death like a real appliance error code, then quietly schedules a funeral for it.

## Run it

```sh
python3 main.py
```

Writes the error message to `/output/entry.txt` (standard library only, deterministic — the same line on every run).
